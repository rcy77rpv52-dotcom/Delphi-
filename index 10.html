Situation

Ticket utilisateur L'application se ferme brutalement de temps en temps quand j'ouvre le detail d'une commande, que je referme la fenetre, puis que j'en ouvre une autre. Ce n'est pas systematique.
uListeCommandes.pas 
unit uListeCommandes;

interface

uses
  Winapi.Windows, System.SysUtils, System.Classes, Vcl.Forms, Vcl.Controls,
  Vcl.StdCtrls, Vcl.Grids, uDetailCommande;

type
  TfrmListeCommandes = class(TForm)
    sgCommandes: TStringGrid;
    btnVoirDetail: TButton;
    procedure btnVoirDetailClick(Sender: TObject);
  private
    function CommandeSelectionneeID: Integer;
  end;

var
  frmListeCommandes: TfrmListeCommandes;
  frmDetailCommande: TfrmDetailCommande;

implementation

{$R *.dfm}

procedure TfrmListeCommandes.btnVoirDetailClick(Sender: TObject);
begin
  if not Assigned(frmDetailCommande) then
    frmDetailCommande := TfrmDetailCommande.Create(Application);

  frmDetailCommande.ChargerCommande(CommandeSelectionneeID);
  frmDetailCommande.Show;
end;

end.
uDetailCommande.pas 
procedure TfrmDetailCommande.FormClose(Sender: TObject; var Action: TCloseAction);
begin
  Action := caFree;
end;

Grille d'evaluation

Usage interne
Question 1 : reponse B - pointeur non remis a nil apres liberation, acces a un objet detruit, plantage non systematique selon l'etat de la memoire.
Question 2 : reponse C - traite la cause. A masque le probleme et change le comportement, B masque l'erreur, D libere un pointeur deja invalide.
Question 3 : reponse B - FastMM FullDebugMode. A ne detecte que les fuites, C et D ne font que contourner.
CritereCe qu'on observeNote
Lecture de code Repere seul le lien entre caFree et la variable globale, sans avoir besoin d'etre guide.
Methode de diagnostic Distingue hypothese et certitude, sait ce qu'il verifierait en premier, connait les outils de debug memoire.
Qualite du correctif Va au-dela du correctif ponctuel : generalisation, revue des autres formulaires, prevention de la recidive.
Communication Reformule sans jargon et sans perdre en justesse, annonce un delai realiste, ne survend pas.
Aisance Delphi Vocabulaire, cycle de vie des objets VCL, gestion memoire, coherence avec l'experience annoncee.
